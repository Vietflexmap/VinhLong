# Vĩnh Long Local

**International local-first travel website for Vĩnh Long, Vietnam.**  
Designed by **Long Ngo · 2026**.

## Vision

Vĩnh Long Local is a destination platform and local-experience marketplace for international visitors. It brings together authentic river life, orchard islands, Mang Thít brick heritage, Khmer culture, Cồn Chim community tourism, cù lao cycling and forest/wetland ecotourism.

## Experience architecture

**Discover → Connect → Request**

- Browse destination experiences by interest
- Meet local host roles and understand their strengths
- Explore routes on an interactive map
- Read cultural and place-based stories
- Submit a custom trip request with dates, pace, group and interests

## Current features

- Real Vĩnh Long photography
- Responsive English-language design
- Experience marketplace filters
- Local host network prototype
- Custom trip request flow stored locally in the browser
- MapLibre GL JS + OpenStreetMap enhancement when online
- Built-in vector route map fallback when offline
- Three route themes:
  - River & Orchard
  - Market & Heritage
  - Khmer & Nature
- Coverage includes Trà Ôn, An Bình, Mang Thít, Cồn Chim, Chùa Âng, cù lao landscapes and nature tourism
- GitHub Pages-ready standalone deployment

## Run locally

Open `index.html` directly in a browser.

The website is intentionally packaged as a self-contained deployment file so the core experience continues to work offline. MapLibre/OpenStreetMap upgrades automatically when an internet connection is available.

## Editorial status

This is a professional prototype. Host identities, operator details, prices, availability, booking/contact information and commercial terms must be verified before public commercial launch.
